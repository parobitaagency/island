# Island

A small Dynamic Island for the MacBook notch, with an iPhone-style lock screen player.

- Compact island: artwork on the left, waveform on the right; trackpad haptic on hover.
- Click the artwork to open the player (Liquid Glass on macOS 26).
- Lock screen: zoomed artwork background, clock, glass player card.
- Music and Spotify via AppleScript.

Build: `Scripts/build.sh` (or push to `main`; GitHub Actions uploads `Island.dmg`).

Uses [SkyLightWindow](https://github.com/Lakr233/SkyLightWindow) (MIT) for the lock screen.
